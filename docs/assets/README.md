# Public media assets

All product media in this directory must use deterministic synthetic telemetry. Before committing an image or animation, inspect visible pixels and metadata for user names, home paths, host names, tokens, private endpoints, prompts, and production telemetry.

- `social-preview.png` is generated from the canonical desktop icon by `scripts/build-readme-assets.py`. It is the source file to upload under **Repository settings → General → Social preview**.
- `otelux-workbench.png` is the full-resolution static README screenshot.
- `otelux-demo.gif` is the GitHub-compatible animated README demo generated by `scripts/build-readme-demo.py` from the privacy-reviewed source captures in `demo-frames/`.

The product captures were made from a clean, isolated OTelux profile through Deskpal after ingesting only the checked-in fixtures `sample_trace.json`, `distributed_trace.json`, `sample_trace_error.json`, `sample_codex_logs.json`, and `sample_codex_metrics.json`. Deskpal verified each visible state before a CDP file-write escape hatch saved the already-verified renderer pixels.

Regenerate the social preview on Linux with Pillow and `rsvg-convert` available:

```bash
python3 scripts/build-readme-assets.py
```

Regenerate the demo GIF with Pillow and FFmpeg available:

```bash
python3 scripts/build-readme-demo.py
```
